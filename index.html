01 / DATASET

Scope & evaluated models

This dashboard displays available verification statistics for seven global guidance systems: GFS, AIGFS, CFS, CMC, ECMWF, FNMOC, and UKMET. The available model group is Global. The available geographic domains are Global, Northern Hemisphere, Southern Hemisphere, and Tropics.

The archive supports up to 90 daily valid dates and Day 0 through Day 15. Only available daily scores are displayed. Current metrics are H500 ACC, T850 RMSE, and MSLP RMSE; other metrics display N/A until published.

Data availabilityUnavailable results show N/A rather than estimated values. Different model coverage can affect comparisons.
02 / DATA AVAILABILITY

Available data

The currently available scores cover 500-hPa height ACC, 850-hPa temperature RMSE, and mean sea-level pressure RMSE. Other metrics are listed as N/A in the selectors and cannot be chosen until verification statistics are available.

Comparisons use the same verification date, forecast lead, region, and metric. The detailed analysis pages also offer a stricter setting that uses only records verified against the same dataset. This can reduce the number of available comparisons.

03 / MEASURES

Verification metrics

ACCHigher is better

Anomaly Correlation Coefficient

Measures how well forecast anomalies align with verifying anomalies relative to a climatological reference. Displayed for 500-hPa geopotential height in the current dashboard.

RMSELower is better

Root Mean Square Error

Measures overall error magnitude in the variable's physical units (K, m, hPa or m/s). Larger errors receive more weight than small errors because differences are squared.

BiasCloser to zero

Mean signed error

Indicates the direction and size of systematic error. Positive and negative values carry different physical meaning; the ranking compares absolute distance from zero, while Time Series retains the signed value.

ETSHigher is better

Equitable Threat Score

Measures categorical precipitation event skill while accounting for hits expected by chance. Planned for 24-hour precipitation; currently unavailable (N/A).

The displayed values are already-computed verification statistics; the dashboard summarizes and compares those statistics rather than calculating them from raw forecasts and observations.

04 / COMPUTATION

Combining daily statistics

For longer periods or the “All forecast leads” option, the dashboard combines available daily verification statistics according to the metric:

MetricHow scores are combinedInterpretation
RMSEsqrt(mean(RMSE²))Accounts for squared error magnitude
ACCtanh(mean(atanh(ACC)))Combines correlation coefficients
Biasmean(signed Bias)Positive and negative bias can offset
ETSmean(ETS)Average of the displayed daily scores

Statistics are combined from the available daily scores. Differences in sample coverage or the number of available records can affect comparisons; interpret small differences with care.

05 / INTERPRETATION

Model ranks, skill, and scorecards

Overall ranking

Home's ranking at left orders models using the aggregated absolute statistic across the selected dates and forecast lead(s): highest ACC/ETS, lowest RMSE, or Bias closest to zero ranks first. It is not the average of daily ranks.

Daily rank history

The Home plot separately ranks all models with a valid score at each individual date. 1 = best (top of chart); larger rank numbers are lower-performing. The lines show rank changes, not raw score changes.

Skill vs Forecast Lead

Each forecast day compares the model's aggregated metric with a selected baseline (GFS by default). Positive percentages indicate improvement and negative percentages indicate degradation. The 0.0% reference is always labeled. Optional gray boxes illustrate estimated significance thresholds; their interpretation and limitations are described below.

Scorecard

Home and full Scorecard both display percentage improvement relative to the chosen baseline for the relevant metric/forecast lead. Baseline cells are 0.0%. Blue indicates positive skill, gray near zero, red negative skill; values are also printed, so color alone is not required.

Time Series

Shows actual metric values for each valid date at a chosen lead, or a metric-specific aggregation across all available leads. It is not baseline-relative. Y-axis units follow the selected metric.

Baseline-relative skill (%)
Higher-is-better: 100 × (model − baseline) / |baseline|Lower-is-better: 100 × (baseline − model) / |baseline|Bias: 100 × (|baseline bias| − |model bias|) / max(|baseline bias|, floor)

When the baseline error is close to zero, percentages can become large and should be interpreted cautiously, especially for Bias. Heatmap color intensity is a visual guide; the printed percentage is the comparison value.

06 / SAMPLING

Dates and forecast leads

The window presets are 7, 15, 30, 60, and 90 days. Each preset ends on the latest available verification date. A Custom Range allows a start and end date within the available 90-day period.

Skill vs Forecast Lead displays Day 0 through Day 15 at whole-day intervals. The detailed Scorecard uses a compact subset: Days 1, 3, 5, 7, 10, and 15. Time Series can show a single lead or combine all available leads. Selected dates and forecast leads determine which statistics contribute to each result.

Chart interaction: Hovering over a model name highlights its line on Home, Skill vs Forecast Lead, and Time Series; hovering over a line also identifies its model. Model-selection controls can show or hide traces without altering the underlying scores. Charts support sampling, zooming, panning, resetting the view, and downloading labeled PNGs. Dark and light themes use the same model colors and marker shapes.

07 / UNCERTAINTY

Estimated statistical significance

Skill vs Forecast Lead can display gray boxes centered on the 0.0% skill reference. Each box spans an estimated threshold above and below zero for one forecast day. The boxes provide an exploratory indication of whether observed differences from the selected baseline are larger than might be expected from day-to-day variability.

Trace beyond the box

For a model with enough matched dates, a trace above or below the box exceeds the conservative estimated pointwise 95% threshold at that lead. This suggests a potentially meaningful difference, not a definitive statistical finding.

Trace within the box

The shared box is an envelope across eligible models. A trace inside it is inconclusive; it does not establish equal performance or rule out a difference under a model-specific test.

Missing box

At least 20 matched verification dates are required for each model–baseline comparison. Leads with no qualifying comparisons have no box; 7- and 15-day windows normally have insufficient dates.

Display and export

The Show estimated significance thresholds control displays or hides the boxes. They update with the selected models, baseline, metric, region, period, and comparison setting, and are included in exported PNGs when shown.

How the thresholds are estimated: Daily model and baseline scores are matched at the same verification dates and forecast lead. The method performs 499 randomized exchanges of model and baseline scores in three-day blocks, recalculating relative skill to estimate the variation expected under no systematic difference. The 95th percentile of the absolute simulated differences determines each eligible model's threshold. For a given lead, the gray box uses the largest threshold among eligible selected models, so a single box can be shown without favoring the least-variable comparison.

Interpretation cautionThese are approximate, pointwise thresholds derived from daily summary statistics—not official EVS significance results or confidence intervals based on the original forecast–observation pairs. Three-day grouping only approximates temporal dependence, and the estimates do not adjust for testing multiple models and forecast leads. A trace without 20 matched dates does not have a valid estimate even if a box is visible for another model.
08 / CAUTIONS

Notable Signals and limitations

Home's Notable Signals compares each model's most recent 15-day period with the preceding 15-day period, using the available headline metrics across forecast leads. It displays up to six of the largest percentage changes. Blue upward arrows indicate improvement; red downward arrows indicate degradation. Stronger shades indicate larger changes, and at least one of each direction is included when both are present.

Signals are an automated way to identify possible changes in recent summary performance. They are not statistical significance tests, forecast alerts, or confirmed changes in model quality. They use fixed 15-day windows rather than the Home ranking chart's selected date range or forecast lead.

  • Small differences in scores do not necessarily imply a meaningful difference in forecast quality.
  • Performance depends on metric, geographic region, forecast lead, verification period, and verifying dataset.
  • Not all models have data for every metric, date, or lead; N/A and gaps represent unavailable information, not zero performance.
  • Combining different forecast leads or comparing models with different coverage can obscure lead-specific differences.
