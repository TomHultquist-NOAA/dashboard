01 / DATASET

Scope & evaluated models

This dashboard displays available verification statistics for seven global guidance systems: GFS, AIGFS, CFS, CMC, ECMWF, FNMOC, and UKMET. The available model group is Global. The available geographic domains are Global, Northern Hemisphere, Southern Hemisphere, Tropics, and CONUS. Upper-air and mean sea-level pressure scores are available in the global domains, while the current 2-m temperature, 10-m wind, and 24-hour precipitation products use the CONUS domain.

The archive supports up to 90 daily valid dates and Day 0 through Day 15. Only available daily scores are displayed. Available metrics include height, temperature, pressure, 10-m wind, and 24-hour precipitation scores. When a metric is available only in another region, selecting it switches to that region across the dashboard pages. The Home scorecard includes its fixed set of metrics, even when the selected ranking metric changes. Each scorecard entry identifies its actual verification domain. Missing scores remain N/A.

Data availabilityUnavailable results show N/A rather than estimated values. Different model coverage can affect comparisons.
02 / DATA AVAILABILITY

Available data

Verification products include 500-hPa geopotential height ACC, RMSE and bias; 850-hPa temperature RMSE and bias; mean sea-level pressure RMSE and bias; 2-m temperature RMSE and bias; 10-m wind vector RMSVE and SPEED_ERR; and 24-hour precipitation ETS at the ≥0.10-inch (2.54-mm) event threshold. Precipitation ETS is recorded as MET GSS and verified at 12 UTC; the other current daily products use 00 UTC. Data availability varies by model, region, date, and forecast lead. Available metrics remain selectable regardless of the current region; selecting a metric available only in CONUS switches the plot to CONUS. Missing model, date, or lead combinations still show N/A.

Comparisons use the same verification date, forecast lead, region, and metric. The detailed analysis pages also offer a stricter setting that uses only records verified against the same dataset. This can reduce the number of available comparisons.

03 / MEASURES

Verification metrics

ACCHigher is better

Anomaly Correlation Coefficient

Measures how well forecast anomalies align with verifying anomalies relative to a climatological reference. Displayed for 500-hPa geopotential height in the current dashboard.

RMSELower is better

Root Mean Square Error

Measures overall error magnitude in the variable's physical units (K, m, hPa or m/s). Larger errors receive more weight than small errors because differences are squared.

MECloser to zero

Bias (mean error)

The mean signed forecast-minus-observation difference for scalar fields. Positive and negative values indicate opposite errors; rankings compare absolute distance from zero, while Time Series shows the signed value.

ETSHigher is better

Equitable Threat Score

Measures categorical precipitation event skill while accounting for hits expected by chance. The 24-hour precipitation event threshold is ≥0.10 inch (2.54 mm).

RMSVELower is better

10-m wind vector error

Root mean square of the full forecast-minus-observed wind vector difference. Includes differences in wind magnitude and direction; it is not scalar wind-speed RMSE.

SPEED_ERRCloser to zero

10-m wind vector speed error

The magnitude of the average forecast wind vector minus the magnitude of the average observed wind vector. This is not the difference between average scalar wind speeds and is not conventional mean vector error.

The displayed values are already-computed verification statistics; the dashboard summarizes and compares those statistics rather than calculating them from raw forecasts and observations.

04 / COMPUTATION

Combining daily statistics

For longer periods or the “All forecast leads” option, the dashboard combines available daily verification statistics according to the metric:

MetricHow scores are combinedInterpretation
RMSE, RMSVEsqrt(mean(score²))Accounts for squared error magnitude
ACCtanh(mean(atanh(ACC)))Combines correlation coefficients
ME, SPEED_ERRmean(signed score)Positive and negative errors can offset
ETSmean(ETS)Average of the displayed daily scores

Statistics are combined from the available daily scores. Differences in sample coverage or the number of available records can affect comparisons; interpret small differences with care.

05 / INTERPRETATION

Model ranks, skill, and scorecards

Overall ranking

Home's ranking at left orders models using the aggregated absolute statistic across the selected dates and forecast lead(s): highest ACC/ETS, lowest RMSE/RMSVE, or ME/SPEED_ERR closest to zero ranks first. It is not the average of daily ranks.

Daily rank history

The Home plot separately ranks all models with a valid score at each individual date. 1 = best (top of chart); larger rank numbers are lower-performing. The lines show rank changes, not raw score changes.

Skill vs Forecast Lead

Each forecast day compares the model's aggregated metric with a selected baseline (GFS by default). Positive percentages indicate improvement and negative percentages indicate degradation. The 0.0% reference is always labeled. The optional EVS-style difference/interval chart uses raw paired daily model-minus-baseline scores in native metric units. The Forecast Hour Mean chart beneath it shows the arithmetic average of available daily absolute verification scores at each forecast hour for each selected model (regardless of baseline pairing). Missing data remain gaps, and sample sizes can differ across models. This average is intentionally distinct from RMS/Fisher aggregation used for relative skill.

Scorecard

Home and full Scorecard display percentage improvement relative to the chosen baseline for each metric and forecast lead. Each metric uses the selected region if available; products not available in the selected domain retain their actual region and are labeled as such, without combining domains in a single metric. Baseline cells are 0.0%. Blue indicates positive skill, gray near zero, red negative skill; values are also printed, so color alone is not required.

Time Series

Shows actual metric values for each valid date at a chosen lead, or a metric-specific aggregation across all available leads. It is not baseline-relative. Y-axis units follow the selected metric.

Baseline-relative skill (%)
Higher-is-better: 100 × (model − baseline) / |baseline|Lower-is-better: 100 × (baseline − model) / |baseline|ME or SPEED_ERR: 100 × (|baseline error| − |model error|) / max(|baseline error|, floor)

When the baseline error is close to zero, percentages can become large and should be interpreted cautiously, especially for signed errors. Heatmap color intensity is a visual guide; the printed percentage is the comparison value.

06 / SAMPLING

Dates and forecast leads

The window presets are 7, 15, 30, 60, and 90 days. Each preset ends on the latest available verification date. A Custom Range allows a start and end date within the available 90-day period.

Skill vs Forecast Lead displays Day 0 through Day 15 at whole-day intervals. The detailed Scorecard uses a compact subset: Days 1, 3, 5, 7, 10, and 15. Time Series can show a single lead or combine all available leads. Selected dates and forecast leads determine which statistics contribute to each result.

Chart interaction: Hovering over a model name highlights its line on Home, Skill vs Forecast Lead, and Time Series; hovering over a line also identifies its model. Model-selection controls can show or hide traces without altering the underlying scores. Charts support sampling, zooming, panning, resetting the view, and downloading labeled PNGs. Dark and light themes use the same model colors and marker shapes.

07 / UNCERTAINTY

EVS-style paired-difference intervals

On Skill vs Forecast Lead, the optional Show EVS-style 95% confidence intervals control displays a separate model-minus-baseline difference chart in the native verification metric units. The existing percentage-skill chart remains unchanged. Model-colored outlined bars are centered on the zero-difference reference, one bar per model and forecast lead with enough paired daily scores.

Beyond the model's outlined bar

A model's daily-mean difference outside its own zero-centered interval indicates that the pointwise 95% interval around that mean does not include zero, under the approximation used by the EVS lead-average plot. It does not necessarily indicate better skill, particularly for signed bias.

Inside the bar

Zero cannot be excluded for that model and forecast lead at the approximate 95% level. Each model has its own bar; there is no shared envelope.

No bar

An interval requires at least 2 matched daily records. Missing model data or dates produce gaps rather than fabricated values. Small samples have unstable uncertainty estimates.

Display and export

The optional panel is off by default. It follows the selected metric, models, region, baseline, dates, and comparison mode, and supports independent hover, zoom, pan and PNG export.

Method: For each model and forecast lead, pair daily scores with the chosen baseline by valid date and lead (and by verification source in Strict mode). Calculate each daily difference as model − baseline and its arithmetic mean. Following EVS global deterministic lead-average plotting, calculate CI half-width = factor × population SD(daily differences) / sqrt(n − 1), with factor 1.960 for n ≥ 80, 2.000 for n = 40–79, 2.042 for n = 20–39, and 2.228 for n = 2–19. The plotted interval bars extend from −CI to +CI around zero.

Interpretation cautionThe formula follows the EVS plotting routine, but these inputs are existing daily regional summary scores, not the original matched forecast/observation events. Inference is pointwise, does not adjust for serial correlation or multiple comparisons, and is not a test of the dashboard's nonlinear percentage-skill aggregation. The sign of a mean difference shows a higher/lower raw statistic, not necessarily improvement; signed bias differences particularly require care.
08 / CAUTIONS

Notable Signals and limitations

Home's Notable Signals compares each model's most recent 15-day period with the preceding 15-day period, using the available headline metrics across forecast leads. It displays up to six of the largest percentage changes. Blue upward arrows indicate improvement; red downward arrows indicate degradation. Stronger shades indicate larger changes, and at least one of each direction is included when both are present.

Signals are an automated way to identify possible changes in recent summary performance. They are not statistical significance tests, forecast alerts, or confirmed changes in model quality. They use fixed 15-day windows rather than the Home ranking chart's selected date range or forecast lead.

  • Small differences in scores do not necessarily imply a meaningful difference in forecast quality.
  • Performance depends on metric, geographic region, forecast lead, verification period, and verifying dataset.
  • Not all models have data for every metric, date, or lead; N/A and gaps represent unavailable information, not zero performance.
  • Combining different forecast leads or comparing models with different coverage can obscure lead-specific differences.
